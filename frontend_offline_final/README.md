# Cubo Frontend Offline

Este paquete contiene una versión estática que funciona sin Node.js ni conexión a internet.

## Uso

1. Abre `index.html` en un navegador moderno (Chrome, Firefox, Edge).
2. También puedes ejecutar un servidor local con `python -m http.server` si lo prefieres.
3. Toda la navegación y funcionalidad se ejecuta en el navegador de forma offline.

## Personalización

- Las imágenes están en `app/images/`.
- Los textos de respuestas están en `app/data/js/`.
- Para modificar las alertas guardadas, limpia `localStorage` desde el navegador.

No se requiere Node.js.
